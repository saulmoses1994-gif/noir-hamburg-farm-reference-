# Backlog — Site-Wide SEO Audit (User Request)

**When to run:** After **Travel Companion Hamburg**, **Girlfriend Experience Hamburg**, **Elite Escort Hamburg** (new) and **High Class Escort Hamburg** (new) cornerstone pages are all live on production.

**Sequenced together with:** The already-scheduled **Internal-Linking Optimization Pass** — both can run in the same audit pass to minimise revalidation cycles.

**Scope of the audit:**
1. **Internal-linking network review**
   - Adjacency matrix of every cornerstone → every other cornerstone.
   - Verify natural, contextual anchors both DE and EN.
   - Symmetric bilingual cross-linking (EN pages mirror DE cross-links).
   - No orphan / weakly-linked pages inside the cluster.
2. **Metadata consistency**
   - Titles ≤ ~65 chars, meta descriptions ≤ ~160 chars.
   - Canonical + hreflang matrix is complete and correct on every page.
   - OG / Twitter card parity across the cluster.
3. **Schema coverage**
   - Service / BreadcrumbList / FAQPage on every cornerstone.
   - Optional: WebSite + Organization on layouts.
4. **Topical structure & content depth**
   - Duplicate-content ratios remain low (< 15 % pairwise).
   - Section/FAQ parity across cornerstones.
   - No sentence-level overlap beyond legitimate boilerplate.
5. **Core Web Vitals**
   - Confirm Desktop 100 / Mobile ~96 baseline preserved after all changes.
6. **Sitemap + robots**
   - All 10 cornerstones in sitemap.
   - No accidental noindex/nofollow.

**Deliverable:** One consolidated audit report; if any tweaks are needed they are applied to preview, re-QA'd, then batch-deployed to production upon approval.

**Comes before:** Blog content strategy + backlink acquisition (next phase after cornerstone cluster is complete).

**Owner:** Main agent, after user approval of High Class Escort Hamburg.
